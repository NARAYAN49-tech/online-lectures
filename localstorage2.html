Store localStorage.setItem("username", "Sandip"); Read const name = localStorage.getItem("username"); console.log(name); Output: Sandip Remove one item localStorage.removeItem("username"); Remove everything localStorage.clear(); Example localStorage.setItem("theme", "dark"); const theme = localStorage.getItem("theme"); console.log(theme); Real-world examples: • Theme preference • Language preference • Simple client-side settings • Shopping-cart data for some applications Don't store sensitive secrets such as passwords or long-lived authentication secrets in localStorage.
